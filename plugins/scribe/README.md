# Scribe plugin

Scribe writes commit messages that explain the reasons for staged changes and tightens prose generated by AI.

Each skill runs only when invoked.

## commit-message

`commit-message` writes a Conventional Commit message that explains the reasons for staged changes.

- It targets all staged changes or only those under named paths.
- It reads recent commit subjects, the diffstat, and the staged patch without lockfiles or minified files.
- It uses named files, such as a handoff, for context and limits claims to patch evidence.
- It limits the subject and body lines to 72 characters.
- It prints the message without committing.

## tighten-prose

`tighten-prose` shortens prose generated by AI without changing meaning.

- It targets prose in staged changes, named paths, or a commit range.
- It covers Markdown, source comments, and doc comments.
- It applies extra rules to skills and agent documents.
- It keeps staged and unstaged changes in their original index state.
- For each file, it reports added and removed lines and any sentence kept verbose to preserve meaning.

## Usage

```text
/scribe:commit-message
/scribe:commit-message plugins/scribe
/scribe:commit-message use action-items/handoff.md as background
/scribe:tighten-prose
/scribe:tighten-prose docs/ main..HEAD
```
